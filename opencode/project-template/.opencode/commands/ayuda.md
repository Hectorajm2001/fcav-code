Muestra un resumen completo de los comandos, temas y habilidades disponibles en **FCAV CODE**:

### 🛡️ Comandos Rápidos Disponibles:
- `/audit-seguridad`: Escaneo de vulnerabilidades OWASP Top 10, inyecciones SQL y protección de datos LGPDPPP.
- `/commit-es`: Analiza el `git diff` y genera un commit en español con estándar Conventional Commits.
- `/design-check`: Valida el cumplimiento del Sistema de Diseño Visual FCAV (colores, tipografía y glassmorphism).
- `/doc-api`: Documenta endpoints RESTful con esquemas de entrada y respuesta JSON.
- `/ayuda`: Muestra este menú de referencia rápida.

### 🎨 Temas Visuales Disponibles:
- `fcav`: Tema oficial institucional (balanceado con fondos oscuros forestales y acentos UAT).
- `fcav-dark`: Modo oscuro de alto contraste basado en tokens CSS.
- `fcav-light`: Modo claro institucional con fondos papel y contraste óptimo.

### 🔌 Plugins & Servidores MCP Integrados:
- `fcav-toolkit`: Detección de secretos expuestos, formateo automático y notificaciones.
- Servidores MCP para SQLite, PostgreSQL, Git y Búsqueda Web (`fetch`).

Presenta esta información de forma visualmente atractiva y limpia.
